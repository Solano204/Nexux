================================================================
 WORKFLOW 1: OnboardingFlowSaga
================================================================
TRIGGER: POST /api/v1/auth/register

  [identity]       → users.registered
  [saga-orch]      ← users.registered → starts saga
  [kyc waits]      (user must call POST /kyc/initiate manually)
  [identity/kyc]   → (S3 upload → KYC pipeline) → identity.verified
  [saga-orch]      ← identity.verified → KycApprovedReply
  [saga-orch]      → saga.commands: CreateAccountsCommand
  [account]        ← CreateAccountsCommand → creates checking+savings
  [account]        → saga.replies: AccountsCreatedReply
  [account]        → accounts.created
  [saga-orch]      → saga.commands: SendWelcomeNotificationCommand
  [notification]   ← SendWelcomeNotificationCommand → sends welcome
  [notification]   → saga.replies: WelcomeNotificationSentReply
  [saga-orch]      → saga.completed ✅

  FAILURE PATH (KYC rejected):
  [kyc]            → identity.rejected → KycRejectedReply
  [saga-orch]      → saga.commands: CancelUserRegistrationCommand
  [identity]       ← CancelUserRegistrationCommand → cancels user

================================================================
 WORKFLOW 2: TransferSaga
================================================================
TRIGGER: POST /api/v1/transactions (requires funded accounts)

  [transaction]    → transactions.initiated
  [saga-orch]      ← transactions.initiated → starts TransferSaga
  [saga-orch]      → saga.commands: ReserveBalanceCommand
  [account]        ← ReserveBalanceCommand → reserves funds
  [account]        → saga.replies: BalanceReservedReply
  [saga-orch]      → saga.commands: CheckFraudCommand
  [fraud]          ← CheckFraudCommand → AI fraud analysis (OpenAI)
  [fraud]          → saga.replies: FraudClearedReply
  [saga-orch]      → saga.commands: PostLedgerCommand
  [ledger]         ← PostLedgerCommand → double-entry journal
  [ledger]         → saga.replies: LedgerPostedReply
  [ledger]         → ledger.posted (via Debezium CDC)
  [saga-orch]      → saga.commands: FinalizeTransferCommand
  [account]        ← FinalizeTransferCommand → commits balance change
  [account]        → saga.replies: BalanceFinalizedReply
  [transaction]    → transactions.completed
  [saga-orch]      → saga.commands: SendTransactionNotificationCommand
  [notification]   → sends to sender + receiver
  [notification]   → saga.replies: NotificationSentReply
  [saga-orch]      → saga.completed ✅

  DOWNSTREAM (parallel to saga completion):
  [audit]          ← transactions.completed, ledger.posted, fraud.result
  [analytics]      ← transactions.completed → Kafka Streams aggregation
  [risk-scoring]   ← user.behavior.aggregated (from analytics)

  FAILURE PATH (fraud rejected):
  [fraud]          → saga.replies: FraudRejectedReply
  [fraud]          → fraud.flagged (→ notification sends FRAUD_ALERT)
  [saga-orch]      → saga.commands: ReleaseBalanceCommand
  [account]        ← releases the hold → BalanceReleasedReply
  [transaction]    → transactions.failed
